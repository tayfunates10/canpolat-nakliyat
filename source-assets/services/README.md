# Hizmet görselleri kaynak kaydı

Bu klasördeki PNG dosyaları, 8 Ağustos 2026 tarihinde seçilen özgün hizmet görselleridir. Web sitesinde kullanılan `assets/images/service-*.webp` dosyaları bu kaynaklardan kırpılmadan ve yeniden ölçeklenmeden lossless WebP olarak üretilir.

| Kaynak | Hizmet kartı |
| --- | --- |
| `service-evden-eve.png` | Evden Eve Nakliyat |
| `service-sehirler-arasi.png` | Şehirler Arası Nakliyat |
| `service-ofis.png` | Ofis Taşıma |
| `service-asansorlu.png` | Asansörlü Taşıma |
| `service-paketleme.png` | Paketleme & Montaj |

Tüm kaynaklar `1586 × 992` piksel ve `793:496` en-boy oranındadır.
